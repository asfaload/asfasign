# Asfaload Documentation

Welcome to the Asfaload documentation. Asfaload is a multi-signature sign-off solution that is:

* open source
* auditable as it is using a public git repo as storage
* self-hostable
* accountless, the keypair is the identity

Asfaload provides tools for signing and verifying software release artifacts.
The Client CLI documentation explains how to use our command line utility to interact with the backend. The REST API details the endpoints of the backend server.
